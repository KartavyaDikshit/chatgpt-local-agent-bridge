# Roadmap

## MVP

- Authenticated local HTTP tools.
- Sandbox-limited file tools.
- Strict command allowlist.
- Optional LM Studio health, models, and ask endpoints.
- In-memory task submission and task status.
- Smoke test with a local mock runtime.

## Near-Term

- Optional MCP transport adapter.
- Persistent task store with redaction.
- More structured tool schemas.
- Better local-runtime adapters.
- Config validator for command allowlists.

## Later

- Desktop setup wizard.
- Signed local connector config export.
- More granular workspace policies.
- Rich audit view for user-approved local actions.

## Out Of Scope

- destructive file operations
- arbitrary terminal access
- credential scraping
- browser cookie access
- admin/system actions
- hosted public bridge service
